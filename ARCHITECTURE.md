## 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 元数据存储 | Pebble (LSM) | 写密集，支持快照，与 Raft log checkpoint 契合 |
| 共识协议 | Raft (hashicorp/raft) | 成熟稳定，支持 PreVote 防止选举风暴 |
| 数据写入 | TCP + 自定义二进制协议 | 减少序列化开销，支持流式传输 |
| 副本写入 | 并行 (非链式) | O(RTT) 而非 O(N*RTT)，延迟更低 |
| WAL 策略 | Group-commit | 批量 fsync，吞吐量优先 |
| 文件格式 | 固定 20B header + data | 简单直接，便于 CRC 校验 |
| 放置策略 | 拓扑感知 + 打分 | 兼顾负载均衡和故障域隔离 |
